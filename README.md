# Scripts_and_Data_for_Ulve_et_al_2026
This repository contains R scripts and datasets used in the paper: “Too hot for symbiosis? Heatwaves disrupt host–microbe interactions in a soil macrofauna decomposer” (Ulvé et al., 2026).

Each dataset is associated with an R script identifiable by the number in the file names (e.g., the R script “1_temperature_scenarios.R” used the dataset “1_temperatures.txt”).

The R script 3_dada2.R is associated with raw sequence reads available online in NCBI with the accession number PRJNA1564915.
